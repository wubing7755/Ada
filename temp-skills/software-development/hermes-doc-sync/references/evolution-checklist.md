# EVOLUTION.md 同步检查清单

每次文档进化收敛后，逐项更新 EVOLUTION.md：

## 数据面板 (必须，6 项)

- [ ] `更新时间: YYYY-MM-DD · 第 N 轮后` — header 行
- [ ] 主文档规模 — 行数
- [ ] 兵器谱规模 — 行数
- [ ] 进化记录条目 — +1
- [ ] 进化轮次 — 更新为当前轮次，附本轮主题描述
- [ ] 文档健康度 — 评估后可能调整

## 趋势表 (必须)

- [ ] 新增一行：轮次 | 日期 | 场景数 | 主文档行数 | 引擎行数 | 新增场景 | 健康度

## 轨迹图 ASCII (必须)

- [ ] R 标记延伸一行（如 R22 → R22 R23）
- [ ] `│` 列延伸一列
- [ ] 新增分支标签（如 `└─ v2.3.0 版本联动`）
- [ ] 底部总结行：更新轮次数和里程碑描述

## 进化记录 (必须)

- [ ] 最新优先插入本轮摘要（置于已有记录之前）
- [ ] 包含：新增能力 / 改动明细 / 本轮数据（场景/行数/模型/环境/工具/收敛类型）

## 可选检查

- [ ] 趋势表列宽对齐（不强制）
- [ ] scene-map.svg 重新生成（仅场景数或类别变化时）
